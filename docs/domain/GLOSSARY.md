# 开源项目选题领域术语

## 参与者与对象

**经营者**：使用雷达筛选项目、决定是否投入教程制作或部署服务的人。首版为项目发起者本人。

**目标用户**：希望利用开源工具完成具体工作的中国个人用户，首批聚焦内容创作、办公自动化与个人效率场景；可能阅读中文教程或购买部署帮助，但付费意愿需另行验证。

**候选项目**：已被发现、等待进一步分析是否具有选题价值的开源项目。

**选题机会**：针对某个开源项目，存在具体用户需求与可补足内容或服务缺口的可能性；不代表已验证付费需求。

## 分析与决策

**中文内容缺口**：现有中文资料在时效、完整性、可操作性或环境适配方面尚未满足目标用户需求的部分。

**决策卡**：汇集选题建议、证据、反证、未知项和下一步行动的项目分析结果。

**交付适配度**：选题所需能力、设备、时间及维护投入与经营者条件的匹配程度。

**选题窗口**：经营者完成内容或服务准备时，目标需求和可补足缺口仍可能存在的时间范围。

**优先实测**：建议投入有时间上限的真实环境验证，不代表已验证可销售。

**先核验**：存在机会但关键事实未知，应先解决具体疑点。

**持续观察**：当前证据不足，等待相关信号变化后重新判断。

**暂不投入**：当前已有理由表明需求、缺口或交付条件不适合投入。

**预测复盘**：使用预先声明的期限和指标，对照当时记录的预测与后来观察到的结果。

**关注度预测**：首版对未来 7 天日均 Star 净增长相较前 7 天变化方向的判断，仅反映关注度代理指标，不代表实际使用或付费需求。

**暂不可预测**：历史观测不足，无法支持既定口径的关注度预测；不是“基本持平”的同义词。

## 选题工作流

**今日选题简报**：帮助经营者每日快速筛选的入口，汇集值得行动的项目、证据依据、下一步核验及已关注项目的变化；没有充分证据时可以没有推荐。

**首轮实测**：经营者对入选项目进行的初步真实环境验证。最新范围不要求雷达执行实测，也不将其作为生成内容的前置条件；未实测不得宣称已验证可用。

**我的选题**：经营者集中跟进已选择项目、核验事项和内容准备的工作集合，保留人工判断与当时依据；不要求先完成实测。

## 内容与服务

**内部项目资料**：供经营者判断用途与部署条件的仓库分析材料，包括环境、依赖、限制和来源；不默认作为公开推广内容。

**对外推广素材**：面向潜在客户介绍工具功能、场景和配置协助的简短文案与图片，不包含完整内部研究材料。

**人工部署服务**：经营者与客户确认范围后提供的搭建、配置或使用指导；不是雷达自动执行的操作。

**生成示意图**：由生图模型创作、用于表达工具场景或功能的图片，不等同真实运行截图或实测证据。
