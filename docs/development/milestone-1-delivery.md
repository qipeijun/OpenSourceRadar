# 首个里程碑交付记录

日期：2026-10-30。状态：核心链路代码已实现，真实 AI 效果验收待配置；不是全部首版需求完成。

## 已实现

- 本地 React 工作台，主入口为“发现新项目”。系统读取 GitHub Trending，经营者不需要先寻找项目或输入链接。
- 获取仓库官方元数据、按稳定仓库 ID 去重与保存，展示来源、采集时间、日榜快照和可解释场景初筛；解析或网络失败不冒充无候选。
- 批量分析先按日榜增量排序，同值按 ID 稳定排序，并保留一个未知场景探索位（批量大于 1 时）；这是首轮实施规则，尚不是经效果验证的长期策略。范围外项目仍可手动触发分析。
- 分开配置 OpenAI/DeepSeek 兼容分析服务与 Responses `web_search` 检索服务。检索结果保存工具实际查询、引用与覆盖限制；引用关联摘要不标为原文或完整教程。
- AI 输出五个选题问题、八维判断、反证、未知项和下一步核验；校验证据 ID 和结构。没有经营者能力画像时，交付适配度明确未知。
- SQLite 保存证据、历次分析与人的决定；人工决定关联分析版本；重分析失败保留旧结果和人工判断。
- 人工补充材料、候选搜索及基础筛选、异步运行进度与错误提示。仅运行中的任务轮询，旧详情响应不会覆盖新选择。
- 默认仅本机访问；密钥留在服务端。停止服务会中止当前请求并停止后续项目。
