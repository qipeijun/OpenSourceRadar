核验日期：2026-10-30。

状态：已完成公开文档、指定版本部分源码与少量只读接口核验；将可借鉴的思路转化为本项目需求补充。尚未运行上游应用、复制上游代码、选定整仓底座或接通产品功能。

本文件是独立补充，不替换主线正在整理的[首版需求](requirements.md)、[任务拆分草案](ticket-breakdown-draft.md)与[领域术语](../domain/GLOSSARY.md)。技术栈、部署方式、预算和工单发布仍遵循主线待定事项。

## 1. 采用方式

采用“借鉴局部能力，自建选题决策”的方式。先完成单项目证据与决策卡，再扩展候选发现和历史观测；当前不将任何上游完整系统确定为本项目底座。

- 首版吸收：先取材料再分析、结构化输出、项目历史快照、单项目重分析、运行过程可追溯。
- 发现能力吸收：Trending 与主题搜索互补、跨来源归并、保留来源和观察时间。
- 后续增强：Hacker News 等外部关注信号、OSSInsight 历史数据、日报推送。
- 本项目独立设计：中国用户需求证据、中文内容缺口、交付成本、反证、人工决策和预测复盘。
- 不自动纳入：英文界面、邮件模板编辑器、十种来源同时接入、公开发布、全量 GitHub 事件数据库。这些不是当前选题闭环的前提。

### OSSInsight：借鉴指标，API 作为可选补充

- 仓库版本：`d98a10e7244cfc9e2d1da02bace1c2a9fe9d7738`。
- [项目说明](https://github.com/pingcap/ossinsight/blob/d98a10e7244cfc9e2d1da02bace1c2a9fe9d7738/README.md)覆盖 Star、Fork、Issue、PR 和贡献者等多维观察。GitHub 元数据识别为 Apache-2.0。
- [公开 API 文档](https://ossinsight.io/docs/api)声明测试版、无需认证及限流；仓库代码许可不等于托管接口的长期服务承诺。
- 采用：用多个活动指标辅助解释关注增长，不把 GitHub 活动量直接当作使用量或付费需求。
- 接入候选：[趋势接口](https://ossinsight.io/docs/api/list-trending-repos)、[Star 历史接口](https://ossinsight.io/docs/api/stargazers-history)。它的趋势榜与 GitHub Trending 是不同来源，不得混成同一排名序列。
- 本次探测：趋势接口 `period=past_24_hours&language=All` 首次 HTTP 200，顶层包含 `type/data/data_quality`，`data` 包含 `columns/rows/result`，`rows` 长度为 0；未完整验证 `result` 和质量说明，不能据此认定没有趋势项目。第二次请求 20 秒超时。
- 本次探测：`pingcap/tidb` 的月度 Star 历史（2026-09-01 至 2026-10-30）请求 20 秒超时。仅说明本次环境下未成功，不推断服务永久不可用或真实历史不存在。
- 结论：暂不作为首版唯一数据源或必需依赖。接入前验证响应结构、时间覆盖、质量标记、时效和历史统计口径。

## 4. AI 分析的具体借鉴与改进

使用四个顺序步骤即可，不预设必须使用多 Agent：

1. **材料整理**：抽取用途、依赖、版本与限制，并关联原始来源；分别标记事实、推断、未知。README 是项目方陈述，不能自行证明稳定性或使用规模。
2. **机会分析**：对照中国用户需求、教程现状和经营者条件，提出具体可做的内容；缺少经营者时间或设备信息时只给条件式判断。
3. **反证检查**：检查需求稀少、免费教程充分、安装已经简单、支持成本过高等反对因素；不同网页转载同一消息不能算独立证据。
4. **行动建议**：输出已有四种决策结果及对应理由，列出最关键的下一步核验和改变建议的条件。人工决定与 AI 建议分开保存。

每条重要结论应关联证据标识；不存在的标识或不支持结论的来源不能被结构校验放过。输出校验失败应保留原因，不能通过补默认值生成一张表面完整的决策卡。

节约分析成本的设计：材料未变化且分析规则、模型配置和经营者条件一致时可复用；这些条件变化时产生新版本。具体缓存形式、调用预算和技术实现待主线选型，不直接照搬上游 URL 缓存。

## 5. 数据口径

- Trending 排名、页面显示的周期新增 Star、两次 API 总 Star 差值、第三方事件统计分别记录，不能互相替代或直接相加。
- 总 Star 差值是两个观测时点之间的净变化，不自动等于新增关注事件数。
- 增速比较要求窗口可比；观测间隔不一致时显示实际区间。增长加速需要至少可比较的多个区间，而非单点总量。
- 未知、未覆盖、请求失败、解析失败和实际数值零必须可区分。
- 榜单未出现某个项目不证明项目停止增长；不能把榜单覆盖外的时间补成零。
- 国际讨论是外部关注证据，中国需求仍需中文内容、用户反馈或后续人工验证支撑。
- 中文内容缺口和付费价值没有在本次上游核验中找到可直接替代本项目工作的实现证据。
