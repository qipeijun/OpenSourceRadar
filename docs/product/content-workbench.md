# 项目分析与推广素材工作台

日期：2026-10-30。状态：本轮需求基线已确认；文末后续确认覆盖正文同名建议。预测口径及技术能力仍待专项核验，不视为已实现。本轮完成需求整理，不表示已实施业务功能或对外发布。

## 目标

自动发现有潜力的开源工具，帮助经营者判断中国用户需求与人工部署服务机会，并将选中的项目转成清晰、有吸引力的中文介绍和平台配图。

核心用户是经营者本人；最终客户是希望使用工具但需要配置协助或使用指导的中国用户。经营者主要承接人工部署服务，不以出售资料包为默认商业模式。

雷达只分析仓库和公开材料，不安装或运行候选项目。人工部署发生在经营者后续服务过程中，不作为当前生成内容的前置条件。

## 需求基线与变更

- 保留自动发现、中文需求与内容缺口分析、每日简报、趋势、比较、人工判断与预测复盘。
- 已确认每天默认深入分析 10 个候选，简报最多突出 3 个行动项目；不足不凑数。比较支持 2–4 个项目。
- 将“是否值得实测”扩展为“是否值得继续核验或准备推广”；不强迫进入实测状态，也不把准备推广等同已验证可部署。
- 新增内部项目资料、平台文案、GPT 配图、人工修改与导出流程。具体生成组合与自动化边界见待确认项。
- 小红书与闲鱼为首批尝试渠道；平台适用性尚未完成规则核验，不能承诺审核通过。

## 功能结构

| 模块 | 用户要完成的事情 | 关键内容 |
| --- | --- | --- |
| 今日机会 | 快速决定今天关注什么 | 推荐依据、待核验项、关注项目变化、采集和分析状态 |
| 项目发现 | 查找和比较候选 | 场景与状态筛选、搜索、2–4 项比较、手动补充入口 |
| 项目研究 | 看懂工具和服务机会 | 中文用途、用户需求、内容供给、环境清单、依赖与限制、证据和趋势 |
| 我的选题 | 管理准备投入的项目 | 保留或放弃的理由、待办、最新分析变化；具体内容状态为下文建议 |
| 素材工作台 | 制作可用于发布的文字与图片 | 渠道选择、文案编辑、图片生成、审核、导出与版本 |
| 设置与运行 | 配置服务并处理失败 | 模型、检索、生图能力、每日批次、任务进度、失败原因及重试 |

## 主流程

1. 系统发现候选，取得带来源和时间的仓库材料，开展中文证据检索与分析。
2. 用户从今日简报或候选库进入项目，查看内部资料，必要时比较项目。
3. 用户选择“准备素材”，选择小红书或闲鱼。选择不等于认可全部 AI 判断。
4. 系统提炼有资料依据的功能和场景，生成对应平台文案草稿。
5. 用户修改标题与重点，再按需生成图片；不从每个候选自动批量生成配图。
6. 用户检查文字和图片，导出所选版本，手动在平台发布。

第 3–6 步是建议的交互设计，生成触发方式与导出组合待确认。订单、支付、自动私信、自动发布与远程部署不在本轮范围。

## 内部与对外内容

### 内部项目资料

包含中文用途、适用人群、主要功能、操作系统、运行时版本、依赖软件、硬件要求、账号/API Key、网络条件、外部收费服务、官方配置步骤入口及关键限制。

每项区分官方明确说明、基于材料的推断、未找到说明；保存来源与采集时间。全局明确未经运行验证，不凭经验补成确定的最低配置。中文教程少不自动等于有部署服务需求。

### 对外文案

结构：具体场景或用途标题 → 两三句核心功能与适用人群 → 自然说明可协助配置或提供使用指导。

写作要求：简短、口语化、有明确用途；不堆技术名词、不写长教程、不以叫卖部署服务开篇。吸引力来自真实功能和场景，不靠夸大承诺、虚构亲测或收益。若某项使用条件会改变客户购买判断，例如必须有显卡或另付 API 费用，应简洁说明。

服务收费、范围和验收尚未约定时不自动填承诺。不能把收费帮助写成免费领取；不生成谐音、暗号或规避审核的表达。仅改变措辞不能使不允许的服务合法上架。

### 平台产物组合（建议默认值）

| 渠道 | 文案 | 图片 |
| --- | --- | --- |
| 小红书 | 3 个备选标题、1 份简短正文 | 封面、功能场景图、适用人群图，共 3 张 |
| 闲鱼 | 1 个商品标题、1 份简洁说明；已确认的服务范围与必要条件 | 主图、用途图、服务说明图，共 3 张 |

上述数量是产品默认建议，不是平台规定。平台尺寸、字符限制、类目及服务规则须在实现发布模板前依据官方信息核验，不预设为已确认事实。

### 图片

使用 GPT 生图能力创作封面或场景示意图。图片内容依据已选文案与仓库功能，不生成伪造运行截图、客户评价、经营收入或实测证明。涉及原项目标志或现有图片时，保留来源并核验可用范围。

建议保留提示词、对应文案版本、生成模型和生成时间；支持单张重做，不强制重做整个包。文字错误、错别字或难以辨认的图片须可退回修改，不直接视作成品。

## 状态与版本（建议）

选题状态与生成任务状态分开：

- 选题：观察中（暂不制作）、准备素材（决定研究并制作）、待审核（已有草稿）、可导出（用户确认当前版本）、已归档（停止跟进）。可导出不代表平台审核通过或服务交付完成。
- 生成任务：等待中、生成中、成功、部分成功、失败。文案成功但图片失败时保留文案，允许只重试失败项。
- 文案、图片分别保留版本；重新生成不覆盖人工修改。资料或文案更新后提示相关素材可能过时，不静默替换已确认内容。

## 导出（建议）

支持一键复制选中文案、下载单张图片、按项目与平台导出素材包。包内仅包含选中的对外文案与图片，不混入内部环境清单、接口配置、密钥和研究备注。内部资料使用独立导出入口。

不自动发布；可由用户手动记录发布链接，但该记录不表示系统已验证上架成功。

## GPT 接入边界

用户指定分析优先使用参考网关的 `gpt-6.1-sol`、Responses 协议及附加请求头，关闭响应存储；连接详情见 workflow-expansion.md。密钥仅服务端保存，不进入输出包或日志。

文本分析、公开检索和生图三种能力分别验证。参考配置不能证明网关支持全部能力；未取得真实生图能力前不把文本回复或占位图当作图片产物。无有效凭据时清楚标记待配置，不伪造成功。

## 验收场景

1. 无需手动提供仓库链接，可从真实自动候选进入研究及素材准备流程。
2. 官方资料缺少硬件要求时，内部资料显示未知，对外内容不宣称普通电脑必然可运行。
3. 选择两个平台后分别得到合适的文案草稿；功能表述能追溯仓库材料，不捏造效果。
4. 生成图片真实返回可用文件；失败明确显示原因并保留已有文案。
5. 修改文案、重新生成图片不会覆盖用户已保留的版本；能识别图片对应哪版文案。
6. 对外素材包不泄露内部资料和服务配置；付费范围未知时不自动生成价格或售后承诺。
7. 可导出状态由用户确认，不以模型自评代替人工审核，不声称平台合规已获保证。
8. 用自动发现的真实项目验证分析和产物质量；测试通过、文件成功生成与可用于发布分别记录。

4. 自动运行时间与时区、预测口径仍沿用原需求待定项，相关任务实施前确定。

## 后续确认：生成与修改

以下确认覆盖上文对应的待定设计：

- 每日自动分析候选；经营者选中项目后生成平台文案，确认方向后按需生成图片。
- 每个平台默认一份简短正文与 3 张配图，标题提供备选；可编辑、复制文案、下载单图及打包导出。对外包不含内部研究资料。
- 支持输入补充要求，结合仓库资料、当前版本和修改描述继续生成；可指定标题、正文、单张图片或整套素材。
- 修改生成新版本，保留旧版以供查看和恢复，不覆盖人工修改；只改指定部分。
- 文案变化影响配图时提示是否同步更新，不自动重做图片。润色不得编造仓库功能或实测效果。
- 支持保留图片布局、调整颜色或标题等局部修改需求；具体执行能力须通过所接生图服务验证，不能将局部编辑失败伪装成成功。

## 后续确认：视觉与服务信息

- 保存可复用的默认视觉风格，统一字体、配色与排版；每个项目可以单独调整，内容随仓库用途变化。
- 支持上传有使用权的参考图，并描述希望参考配色、布局等具体方面；不自动照搬品牌、功能或宣传承诺。上传参考图不代表已授权将其中人物或品牌用于商业宣传。
- 保存“我的服务信息”，包括可承接的环境、使用指导范围及不承接的需求，每个项目可以覆盖调整。
- 未明确的服务信息留空，只使用通用配置协助说明，不生成未经确认的价格、完成时间、适配承诺或售后期限。
- 内部备注与对外服务信息分开，内部备注不自动进入公开文案。

## 最终确认：运行节奏与交付顺序

- 每日默认北京时间 09:00（Asia/Shanghai）自动发现项目，深入分析最多 10 个候选；设置中可修改执行时间。电脑或服务未运行时，恢复后仅补一次当前采集，不伪造历史，也不按遗漏天数累加分析批次。
- 文案与图片仍由经营者选题后触发，不随每日发现自动批量生成。
- 下一阶段优先交付：自动发现 → 真实 GPT 分析 → 内部中文资料与环境清单 → 选择项目 → 小红书/闲鱼文案与配图 → 补充要求修改 → 导出。
- 同期修复审计发现的分析缺口，并开始保存真实趋势观测。比较、每日简报和选题管理随后补齐，不取消既有要求。
- 7 天预测在真实历史充分且口径确定后验收，不阻塞素材流程。预测容差、数据完整性与评价口径留待预测任务专项确认。
- 网关鉴权、检索与生图接口属于技术核验；有效密钥尚未提供，不能将占位内容当作可用凭据。平台规则核验仍为未完成项。

## 开发切片与验收顺序

| 顺序 | 完整切片 | 完成证据 |
| --- | --- | --- |
| 1 | GPT 接入与分析可靠性 | 核实 Responses、附加请求头、存储关闭及鉴权；修复需求/缺口证据门槛、无结果检索、初筛误排除和输入溯源；真实候选产出可追溯分析，不用模拟结果代替 |
| 2 | 内部项目资料 | 从真实仓库生成中文用途和环境清单；缺失要求标未知、保留来源、不要求运行仓库 |
| 3 | 双平台文案 | 用户选题后生成短文案和标题备选；围绕功能场景，自然说明协助；采用已填写的服务信息，不泄漏内部备注 |
| 4 | GPT 配图 | 验证实际网关生图及参考图能力；默认 3 张，可采用统一风格及参考图；失败不冒充生成成功，保留文字产物 |
| 5 | 迭代与导出 | 按补充要求修改指定文字或图片，产生新版本，保留人工编辑；导出选中版本的文案与图片，不含内部资料和配置 |
| 并行基础 | 趋势采集 | 保存真实观测时间、来源与指标，记录缺口，不补造历史；为后续趋势与预测提供基础 |
| 后续 | 每日调度、简报、比较与选题管理 | 按已确认时间与恢复规则运行；简报最多突出 3 个行动项目，支持 2–4 项比较，保存人工选择和素材进度 |
| 历史充分后 | 预测与复盘 | 先固定口径，再以当时数据预测，按期限复盘；不以素材生成成功证明预测有效 |

各切片都包含相关界面、保存与失败处理、针对性验证。首阶段验收须从系统发现的真实项目走通素材导出；文案质量、图片质量与平台发布适用性分别评价，不用测试通过替代真实效果。没有自动发布、平台账号操作或远端写入授权。
